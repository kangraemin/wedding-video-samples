사진과 문구만 넣으면 자동으로 렌더되는 템플릿으로 만든 결과물이다. 사진은 예시용 무료 이미지, 이름·날짜도 예시.

장면 블록 라이브러리 — 조합 샘플 29편

장면 블록 30종과 테마 6종을 곡의 흐름(도입·고조·마무리)에 맞춰 자동으로 조합했다. 같은 블록이 연달아 나오지 않게 짰고, 사용자가 편집기에서 장면을 바꿔 끼울 수 있는 구조다. 각 영상 아래에 쓰인 블록 순서를 적었다.

장면 블록 30종 미리보기

조합의 재료가 되는 블록 하나하나의 짧은 미리보기.

스타일 12종

같은 템플릿을 반복하는 느낌을 없애려고, 연출 방식 자체가 다른 스타일 12종을 각각 다른 사진으로 만들었다(30~45초).
